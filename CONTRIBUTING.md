
# Contributing to APCA Server Automation

Thanks for your interest in contributing!

## How to Contribute

1. Fork the repository
2. Clone your fork
3. Create a new branch (`git checkout -b feature-yourFeature`)
4. Commit your changes with meaningful messages
5. Push to your fork
6. Submit a Pull Request to the `dev` branch

## Code Style

- Python scripts should follow [PEP 8](https://pep8.org)
- Bash scripts should be POSIX-compliant
- Keep features modular where possible

## Feature Suggestions

Open an issue with:
- Feature title
- Context or problem it's solving
- Example usage

We use [Monday.com](https://monday.com) internally for roadmap tracking.

Happy coding!
